# Резерв — демо-платформа подбора складов

Одностраничный статический сайт на React и Vite. Демо работает локально в браузере: данные объектов синтетические, сервер, база данных, авторизация и ключи не используются.

## Локальный запуск

Требуется Node.js 20 или новее.

```sh
npm install
npm run dev
```

Vite напечатает локальный адрес для браузера. Для предпросмотра production-сборки используйте `npm run build` и `npm run preview`.

## Публикация на GitHub Pages

Workflow `.github/workflows/pages.yml` собирает и публикует сайт при push в `main`. В настройках репозитория откройте **Settings → Pages** и выберите **GitHub Actions** как источник. Vite автоматически подставит base path `/<имя-репозитория>/` из `GITHUB_REPOSITORY` при этой сборке.

Для локального production-сборочного прогона используйте `npm run build`. Если публикуете вручную в корневой домен `username.github.io`, соберите с `VITE_BASE=/` (например, `VITE_BASE=/ npm run build`). Для другого хостинга задайте нужный публичный путь через `VITE_BASE`.

## Ограничения демо

Объекты, ставки, доступность и расчёты условные. Изменение количества паллет и срока пересчитывает TCO по простой формуле `(хранение за паллето-день + операции за паллето-день) × паллеты × дни`. Предварительная заявка остаётся в браузере и может быть скопирована; реальное размещение, наличие, тариф и совместимость подтверждает оператор склада. Сайт не передаёт персональные данные и не выполняет бронирование.
