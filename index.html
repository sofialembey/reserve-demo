Для просмотра запустите локальный сайт

Этот проект использует React и Vite, поэтому его нельзя открыть двойным нажатием на index.html. Откройте терминал в папке проекта и выполните:

npm install
npm run dev

Затем откройте адрес, который напечатает Vite (обычно http://localhost:5173).
